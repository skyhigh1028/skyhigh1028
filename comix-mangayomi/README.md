# Comix Mangayomi Extension

Mangayomi JavaScript source for Comix.to.

## Repository URL

`https://raw.githubusercontent.com/skyhigh1028/skyhigh1028/main/comix-mangayomi/index.json`

## Notes

This source uses the unofficial Comix API proxy for catalogue/chapter/image extraction. Comix's current reader API uses encrypted responses and rotating request tokens, so direct extraction from a simple Mangayomi HTTP client is not reliable.

This repository is for personal use. Respect Comix.to's terms and applicable copyright laws.
